# AskNemuAI 🚀

> Your Intelligent AI Companion for Learning, Innovation, and Success.

**AskNemuAI** is a premium, modern, responsive, and visually stunning AI startup landing page. It is built to showcase a futuristic AI interface utilizing cutting-edge design concepts, responsive grid systems, and custom interactive capabilities.

---

## 🎨 Design Features

* **Futuristic Dark-Mode Interface**: An immersive theme using Deep Space Black, Neon Blue, and Electric Coral accents.
* **Glassmorphism Design**: High-fidelity translucent cards, headers, and buttons leveraging Apple Vision Pro aesthetics.
* **Ambient Neon Glows**: Interactive hover highlights on cards and CTA elements.
* **Neural Network Background**: A dynamic HTML5 canvas particle system that connects nodes and reacts to mouse interactions.
* **Scroll-Triggered Counters**: Stats counters animate dynamically when scrolled into view.
* **Responsive Layout**: Seamless presentation across mobile, tablet, and desktop viewports.

---

## ⚙️ Core Modules

1. **Features Matrix**: An interactive showcase of features (AI Chat, Academic Support, Career Guidance, Productivity, Business Insights, 24/7 Availability).
2. **Interactive Triage Chatbot**: Includes a floating hexagon toggle button and specialized presets for WFH Income ideas and a simulated Medical Consultant.
3. **Contact Validation**: Implements real-time input checks and glassmorphic feedbacks.

---

## 🛠️ Technology Stack

* **Structure**: Semantic HTML5 markup
* **Styling**: Vanilla CSS3 (Custom Variables, Flexbox/Grid, Keyframe Animations)
* **Interactivity**: Pure ES6+ JavaScript (Canvas API, Intersection Observer API)
* **Icons**: FontAwesome CDN

## 🚀 Local Installation & Preview

To run the project locally, clone the repository and start a local web server:

```bash
# Clone the repository
git clone https://github.com/rithanr5127/AskNemuAI.git

# Navigate to the folder
cd AskNemuAI

# Run a local server (e.g., using Python or http-server)
python -m http.server 8000
# or
npx http-server -p 8000
```

Open your browser and navigate to `http://localhost:8000` to view the website.
